# Feature Modules

This directory contains domain-specific feature modules for Checkpoint according to `document/ALICA_CHECKPOINT_API_DOCUMENTATION.md`:

- `auth/` - Authentication & JWT token handling
- `users/` - User account management & roles (Admin, Organizer, Staff)
- `events/` - Event management, schedules, and configurations
- `checkpoints/` - Checkpoint locations and scan stations
- `attendees/` - Attendee registration & RSVP management
- `tickets/` - QR ticket issuance, verification, and check-in logs
